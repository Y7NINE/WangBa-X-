# 大厅选座与管理端水墨视觉更新

更新日期：2026年10月17日。以下为本地运行实拍，数量、订单和营收来自当前演示环境，会随操作变化。

## 顾客选座：先看大厅，再选座

![顾客端大厅示意图](images/ink-hall.png)

选座页默认进入大厅示意，展示入口、前台、区域座位、通道及茶饮服务标识。可以筛选竞技区、休闲区、独立包间，也可以切换到原有座位列表。

| 体验 | 本轮行为 |
|---|---|
| 查看分布 | 显示区域名称、小时单价、空闲数量和每个座位编号 |
| 选择座位 | 点击空闲座位，进入原有上机确认和计费流程 |
| 识别不可用座位 | 使用中、故障、待清理和清理中均有文字和颜色提示，并禁用选择 |
| 接收实时变化 | 沿用后端实时状态事件，座位图与列表共享同一份数据 |
| 键盘操作 | 座位使用原生按钮，可以聚焦并操作；宽布局支持在区域内横向滚动 |

图中座位优先按区域内已有的positionX/positionY坐标排列；缺失、重复或无效时按自然编号生成示意排列。坐标只用于表达相对位置，不表示真实距离。入口、前台、茶饮与区域之间的位置为示意，尚未接入门店实测平面图或装修布局编辑器；该页面不是多人连座预约功能。

## 管理端：与顾客端统一的水墨工作台

![管理端数据大盘](images/ink-admin-dashboard.png)

管理端采用与顾客端相同的宣纸底色、墨色文字、松绿操作和朱砂印记。左侧导航改为浅纸色，当前菜单用细朱砂线和淡松绿强调；页面标题用宋体，数字保留清晰的阅读层级。

顶部保留面包屑、连接状态、演示标识和员工入口，新增页面说明与日期。侧栏可收起，折叠按钮支持键盘操作。

本轮还移除了大盘中写死的营收、人次、趋势序列和涨跌百分比：今日统计及本周/本月趋势读取已有报表接口，加载失败显示提示。

## 表格与弹窗：风格一致，状态清楚

![水吧订单表格](images/ink-admin-orders.png)

订单、计费、会员、故障、保洁、交班、报表等页面统一了底色、边框、圆角和状态色。表格改为纸色表头、细分隔和更宽松的行距；主操作使用松绿，取消、故障等需要关注的内容保留朱砂色。

![工单详情弹窗](images/ink-admin-dialog.png)

弹窗和表单使用同一套字体与颜色。装饰集中在品牌、标题和登录页，业务页面以数据与操作为主，不铺满山水图案。

## 登录页：保持与顾客首页的关联

![管理端水墨登录页](images/ink-admin-login.png)

登录页左侧复用项目原创SVG山水，右侧为员工表单，保留原有登录流程。小屏隐藏装饰侧栏，表单独立呈现。本轮未复制外部品牌图片或标识。
