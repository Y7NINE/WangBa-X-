# 项目能力与边界

当前定位：全栈业务系统本地演示。更新时间：2026年10月21日。

## 能力地图

| 模块 | 当前实现 | 后续边界 |
| --- | --- | --- |
| 身份与岗位 | 双主体JWT；员工岗位菜单/路由/接口；会员字段白名单；部分操作者审计 | HTTP令牌即时撤销与完整审计待补 |
| 上机与计费 | 费率快照、暂停恢复、结算与重复扣款保护、欠费固定账单 | 包夜/套餐、余额耗尽自动下机与硬件控制未实现 |
| 充值 | 严格请求、UUID去重、结果查询、流水及真实操作员 | 演示入账，不对接支付渠道 |
| 水吧订单 | 后端定价、扣款、请求幂等、超时确认、履约、一次性取消退款 | 库存、真实收款退款、业务推送待补 |
| 报修 | 当前会话归属、接单、本人技师处理、换机迁移、原机维修与保洁 | 自动硬件监测和其他扩展状态未完成 |
| 实时与恢复 | 鉴权、授权主题、工单本人隔离、四个工单节点推送；管理端列表快照补偿 | 顾客通知/会话恢复、订单/保洁页恢复、持久化重放未完成 |
| 数据与运行 | 独立演示SQLite、单进程事务队列、内存库回归、三端构建 | Docker/CI/真实PostgreSQL与多实例待验收 |

## 员工入口

| 岗位 | 当前导航 |
| --- | --- |
| 店长/经理 | 大盘、座位、故障、计费、用户、保洁、订单、报表、设置 |
| 收银 | 大盘、座位、故障、计费、用户、保洁、订单、报表 |
| 技师 | 故障、座位 |
| 保洁 | 保洁、座位 |

动作权限比页面更细：技师只处理本人已接工单；保洁任务按本人归属处理，管理岗允许协调。交接班、悬赏和唤醒保留历史代码，暂不提供员工导航；没有真正发奖或硬件唤醒调度。
