# 用户端 · 水吧点单

![用户端效果图](../../网吧用户端效果图/用户端效果图.png)

## 能力说明

在线浏览水吧菜单、加入购物车、提交订单送到座位。

## 界面标注

① **菜单列表** — 饮品/小食图片、名称、价格<br>
② **购物车** — 已选商品、数量、总价<br>
③ **提交订单** — 生成订单并送达座位<br>
④ **订单状态** — 备餐中 / 配送中 / 已完成

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/orders` | 提交订单 `{items, total, remark}` |
| GET | `/orders?status=` | 订单列表 |
| PATCH | `/orders/:id/status` | 更新订单状态 |
