# 用户端 · 座位

![用户端效果图](../../网吧用户端效果图/用户端效果图.png)

## 能力说明

查看网吧布局与实时座位状态，点击空闲座位直接上机。

## 界面标注

① **区域切换** — 竞技区 / 休闲区 / 包间<br>
② **座位图** — 颜色区分状态（空闲/使用中/故障/保洁中）<br>
③ **座位详情** — 机器编号、区域、单价、状态<br>
④ **上机按钮** — 确认上机，开始计费

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/machines?areaId=` | 机器列表 |
| GET | `/areas` | 区域列表 |
| POST | `/billing/sessions` | 开始上机 |
