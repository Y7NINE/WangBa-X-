# 用户端 · 登录

![用户端效果图](../../网吧用户端效果图/用户端效果图.png)

## 能力说明

顾客通过手机号 + 验证码登录。新用户自动注册。开发环境验证码固定 `123456`。微信登录暂未开放。

## 界面标注

① **手机号输入** — 11 位手机号<br>
② **验证码输入** — 开发环境固定 `123456`<br>
③ **登录按钮** — 提交登录<br>
④ **微信登录** — 暂未开放（禁用态）

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/auth/customer/login` | 顾客登录 `{phone, code}` → `{token, user}` |
| GET | `/auth/customer/profile` | 获取顾客信息 |
| POST | `/auth/customer/logout` | 退出登录 |
