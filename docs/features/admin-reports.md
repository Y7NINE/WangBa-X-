# 数据报表

![数据报表](../../网吧管理系统效果图/数据报表.png)

## 能力说明

营收趋势、上座率、故障统计、时段分布热力图。支持按日/周/月切换与自定义时间范围，可导出报表。

## 界面标注

① **筛选栏** — 日期范围、区域筛选、导出按钮<br>
② **核心指标卡** — 营收、人次、平均上座率、平均上机时长<br>
③ **营收趋势图** — 按日/周/月折线图<br>
④ **按机器明细** — 各机器营收/次数/时长/故障数<br>
⑤ **按区域明细** — 各区域汇总数据<br>
⑥ **故障统计** — 按类型/状态分布

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/analytics/overview?from=&to=` | 总览统计 |
| GET | `/analytics/machines?from=&to=` | 按机器统计 |
| GET | `/analytics/areas?from=&to=` | 按区域统计 |
| GET | `/analytics/hourly?date=` | 时段分布 |
| GET | `/analytics/faults?from=&to=` | 故障统计 |
