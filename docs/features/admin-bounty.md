# 悬赏任务

![悬赏任务](../../网吧管理系统效果图/悬赏任务.png)

## 能力说明

游戏化运营工具：拉新任务、驻场任务、签到任务、成就徽章。提升用户粘性与复购率。

## 界面标注

① **任务列表** — 任务名称、类型、奖励、进度、状态<br>
② **新建任务** — 选择任务类型、奖励类型与数量<br>
③ **用户进度** — 查看各用户完成情况<br>
④ **徽章管理** — 成就徽章配置

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/bounty/tasks` | 任务列表 |
| GET | `/bounty/tasks/:id` | 任务详情 |
| GET | `/bounty/progress` | 用户进度 |
| POST | `/bounty/tasks/:id/claim` | 领取奖励 |
