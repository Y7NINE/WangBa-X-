# 智能唤醒

## 能力说明

通宵包夜叫醒服务。支持耳机/灯带/屏幕/人工多种唤醒方式，可设置重试间隔与最大重试次数。

## 界面标注

① **配置列表** — 机器、唤醒时间、唤醒方式、重试设置、状态<br>
② **新建配置** — 选择机器、时间、唤醒方式<br>
③ **操作** — 取消唤醒

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/wakeup/configs` | 唤醒配置列表 |
| POST | `/wakeup/configs` | 创建唤醒配置 |
| DELETE | `/wakeup/configs/:id` | 取消唤醒 |
