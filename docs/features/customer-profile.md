# 用户端 · 个人中心

![用户端效果图](../../网吧用户端效果图/用户端效果图.png)

## 能力说明

查看余额、积分、会员等级、上机记录、消费记录。支持结束当前上机会话。

## 界面标注

① **账户摘要** — 余额、积分、会员等级<br>
② **当前上机** — 机器/时长/费用，一键下机<br>
③ **上机记录** — 历史会话列表<br>
④ **消费记录** — 交易流水

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/auth/customer/profile` | 个人信息 |
| GET | `/billing/sessions?userId=` | 上机记录 |
| PATCH | `/billing/sessions/:id/end` | 下机结算 |
| GET | `/billing/transactions?userId=` | 交易记录 |
