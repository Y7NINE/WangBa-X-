# 数据大盘

![数据大盘](../../网吧管理系统效果图/数据大盘.png)

## 能力说明

实时展示网吧运营核心指标：营收、上座率、在线机器、故障告警。支持 WebSocket 秒级刷新。

## 界面标注

① **顶部指标卡** — 今日营收、当前上座率、在线机器数、待处理故障<br>
② **座位状态总览** — 各状态机器数量（在线/离线/故障/保洁中）<br>
③ **营收趋势图** — 近 7 日营收折线<br>
④ **实时告警** — 故障与异常事件推送列表

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/machines/stats/overview` | 机器状态统计 |
| GET | `/analytics/overview` | 营收/上座率总览 |
| GET | `/faults/tickets?status=pending` | 待处理故障 |
| WS | Socket.IO `machine:update` | 实时状态推送 |
