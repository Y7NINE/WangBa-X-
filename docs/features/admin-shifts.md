# 交接班

![交接班](../../网吧管理系统效果图/交接班.png)

## 能力说明

盲审交接系统，防止财务漏洞。交班/接班双向确认，自动核对现金、上机数、充值额。

## 界面标注

① **交接班记录** — 时间、交班人、接班人、现金金额、状态<br>
② **发起交接** — 选择接班员工、班次类型、备注<br>
③ **盲审核对** — 系统自动比对账目差异<br>
④ **确认完成** — 双方签字确认

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/shifts` | 交接班记录 |
| POST | `/shifts` | 发起交接班 |
