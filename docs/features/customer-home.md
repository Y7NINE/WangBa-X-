# 用户端 · 首页

![用户端效果图](../../网吧用户端效果图/用户端效果图.png)

## 能力说明

展示当前上机状态、快捷入口（选座、报修、点单）、个人余额与积分。

## 界面标注

① **当前上机卡片** — 机器编号、已用时长、预计费用<br>
② **快捷入口** — 选座上机 / 一键报修 / 水吧点单<br>
③ **个人摘要** — 余额、积分、会员等级<br>
④ **公告/活动** — 悬赏任务与促销信息

## 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/billing/sessions?userId=&status=active` | 当前上机会话 |
| GET | `/machines` | 机器列表 |
| GET | `/auth/customer/profile` | 个人信息 |
